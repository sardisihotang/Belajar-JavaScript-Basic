## 📌 Tentang Proyek / About the Project

**[ID]** Repositori ini berisi kumpulan materi dan latihan fundamental JavaScript (Vanilla JS), dengan fokus utama pada pemahaman dan manipulasi *Document Object Model* (DOM). Proyek ini mendokumentasikan proses belajar dari tahapan menyeleksi elemen dasar hingga membangun interaksi dinamis dan *mini-game* berbasis web.

**[EN]** *This repository contains a collection of fundamental JavaScript (Vanilla JS) materials and exercises, focusing primarily on understanding and manipulating the Document Object Model (DOM). It documents the learning process from basic element selection to building dynamic web interactions and mini-games.*

---

## 📂 Struktur Direktori / Directory Structure

Pembelajaran disusun ke dalam beberapa folder berdasarkan topik DOM:

* **`DOM Selection`** - Teknik memilih elemen HTML menggunakan JavaScript (`getElementById`, `querySelector`, `querySelectorAll`, dll).
* **`DOM Manipulation`** - Memanipulasi isi konten, gaya (CSS), dan atribut elemen HTML secara dinamis.
* **`DOM Event`** - Memberikan interaksi pada halaman web dengan mendengarkan aksi pengguna (seperti klik tombol, *hover*, atau input *keyboard*).
* **`DOM Traversal`** - Menjelajahi silsilah elemen DOM untuk menyeleksi *parent*, *child*, atau *sibling* dari sebuah elemen.
* **`Latihan DOM`** - Latihan praktis untuk menggabungkan konsep *Selection*, *Manipulation*, dan *Event*.
* **`Latihan Game SUWIT`** - Proyek *mini-game* interaktif "Suwit Jawa" (Batu-Gunting-Kertas) yang mengimplementasikan logika JavaScript dan manipulasi DOM penuh.
* **`Latihan Akhir`** - Proyek komprehensif yang menguji seluruh pemahaman fundamental DOM secara bersamaan.
